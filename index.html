    How this app uses JSON
    
          
    The starting data is the file data.json, read with fetch:
    

    const res  = await fetch("data.json");
const data = await res.json();
    
          
    Every change is saved in the browser as a JSON string:
    

    localStorage.setItem(KEY,
  JSON.stringify(db));
    
          
    and turned back into an object on the next visit:
    

    db = JSON.parse(
  localStorage.getItem(KEY));
    
          
    Try the Editor: remove a comma or a quote, then press Apply changes to see the SyntaxError JSON.parse throws.
